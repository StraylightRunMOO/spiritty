Features

🚀 GPU Acceleration

WebGL-powered rendering for smooth 60fps performance even with massive output

🎨 True Color Support

Full 24-bit RGB color support with ANSI 256-color and 16-color fallback

📏 Advanced Text

Bold, italic, underline, strikethrough with proper font rendering

🖱️ Mouse & Selection

Full mouse support with text selection, copy/paste, and scrolling

⌨️ Full ANSI Support

Complete VT100/ANSI escape sequence parsing with xterm compatibility

🌐 Web Native

Designed for the browser with responsive design and touch support

Click "Run Demo" to see Spiritty in action, or type in the terminal above. The terminal supports:

  • Keyboard: Arrow keys, Home/End, Page Up/Down
